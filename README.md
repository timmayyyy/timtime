# TimTime (now Ascend Time)

This repository only exists to keep one address alive: `https://timmayyyy.github.io/timtime/appcast.xml`.
Copies of Ascend Time (formerly TimTime) check that address for updates. Removing it would stop those updates.

The app lives at https://github.com/timmayyyy/ascend-time. Keep `appcast.xml` here identical to the one there.
